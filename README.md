# Password Security Auditor

**Author:** MD Waseem  
**Project:** Beginner Cybersecurity / Python

## Description
This educational project evaluates a test password using simple rules: length, lowercase and uppercase letters, digits, symbols, and a small list of common example passwords. It displays a rating and improvement tips.

## Technologies
- Python 3
- Jupyter Notebook
- Python standard library (`re`)

## Files
- `MDWaseem_PasswordSecurityAuditor.ipynb` — project code and demo
- `requirements.txt` — dependency list
- `MDWaseem_PasswordSecurityAuditor_ProjectReport.docx` — project report
- `README.md` — project instructions

## Setup and run
1. Install Python 3.
2. Open this notebook using Jupyter Notebook or JupyterLab.
3. Run all cells from top to bottom.
4. To test another password, replace the sample value in the last cell with a **test password**.

No third-party Python libraries are required for the notebook.

## Privacy and limitations
The notebook does not save or transmit the password. Use only test passwords during demonstrations, never real account passwords. This simple educational checker is not a guarantee of password security. Use unique passwords and multi-factor authentication.

## Dataset
No external dataset is used. A small set of common example passwords is included in the code for demonstration.
